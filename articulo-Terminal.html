Entendiendo la Interacción del Usuario: Construyendo una Mini-Calculadora en JavaScript

05 de diciembre de 2023

En el mundo del desarrollo web, la interacción con el usuario es fundamental. Desde simples botones hasta complejos formularios, JavaScript nos permite dar vida a nuestras interfaces. En este artículo, analizaremos un ejemplo sencillo pero ilustrativo: una mini-calculadora que toma dos números y muestra su suma. Este ejercicio nos ayudará a comprender los fundamentos de la manipulación del DOM (Document Object Model) y el manejo de eventos en JavaScript puro.

1. Capturando Elementos del DOM

Antes de poder interactuar con los elementos HTML desde JavaScript, necesitamos 'capturarlos'. Esto se logra comúnmente utilizando métodos como document.getElementById(), que nos permite obtener una referencia a un elemento específico mediante su ID único. En nuestro ejemplo, identificamos el botón de ejecución, los dos campos de entrada de números y el área donde se mostrará el resultado en la "terminal". 


let btnEjecutar = document.getElementById("btn-ejecutar");
let num1 = document.getElementById("num1");
let num2 = document.getElementById("num2");
let salida = document.getElementById("salida-terminal");

2. Respondiendo a la Interacción: El Event Listener

Una vez que tenemos referencias a nuestros elementos, el siguiente paso es hacer que la página responda a las acciones del usuario. Para el botón 'Ejecutar', adjuntamos un 'event listener' utilizando addEventListener(). Este método espera dos argumentos: el tipo de evento que queremos escuchar (en este caso, 'click') y una función (callback) que se ejecutará cada vez que ocurra ese evento. Es dentro de esta función donde definimos qué sucederá cuando el usuario haga clic. 


btnEjecutar.addEventListener("click", () => {
    // Aquí irá la lógica de nuestra calculadora
});

3. Procesamiento y Presentación de Resultados

Dentro de la función del evento, es donde ocurre la lógica principal. Es importante recordar que los valores de los campos de entrada HTML (``) siempre se obtienen como cadenas de texto, incluso si el usuario introduce números. Por lo tanto, es crucial convertirlos explícitamente a tipos numéricos (usando la función Number()) antes de realizar cualquier operación matemática. Finalmente, el resultado se inyecta en el elemento de salida utilizando la propiedad textContent, que es una forma segura de mostrar texto, y las plantillas de cadena (template literals) para construir un mensaje claro y dinámico. 


    let resultado = Number(num1.value) + Number(num2.value);
    salida.textContent = `El resultado es = ${resultado}`;

Juntando todas las piezas, este es el código JavaScript completo de nuestro ejemplo de mini-calculadora: 


// Primero capturo los inputs de interés
let btnEjecutar = document.getElementById("btn-ejecutar");
let num1 = document.getElementById("num1");
let num2 = document.getElementById("num2");
let salida = document.getElementById("salida-terminal");

// Creo luego un evento click y como función (el segundo parámetro) le pido
// que guarde el resultado en una variable para luego inyectarlo en HTML con textContent.
btnEjecutar.addEventListener("click", () => {
    let resultado = Number(num1.value) + Number(num2.value);
    salida.textContent = `El resultado es = ${resultado}`;
});

Conclusión: Este pequeño ejemplo ilustra cómo JavaScript interactúa con el HTML para crear experiencias dinámicas. Desde la selección de elementos hasta la respuesta a eventos y la manipulación de datos, estos son los bloques de construcción básicos para cualquier aplicación web interactiva. Con estos fundamentos, estás listo para abordar interacciones más complejas y llevar tus proyectos al siguiente nivel. ¡Anímate a experimentar!
