Explorando las Novedades de ES2023: Métodos de Arrays Inmutables

15 de noviembre de 2023

ECMAScript 2023 (ES2023) trae consigo una serie de mejoras interesantes, pero sin duda, una de las adiciones más bienvenidas para el desarrollo diario son los nuevos métodos de arrays que operan de forma inmutable. Esto significa que en lugar de modificar el array original, estos métodos devuelven una nueva copia del array con los cambios aplicados, promoviendo una programación más funcional y predecible. Esto es especialmente útil en contextos donde la inmutabilidad es clave, como en la gestión de estados en aplicaciones React o Vue.

Los Nuevos Métodos de Arrays

Los métodos que se han añadido son toSorted(), toReversed(), toSpliced() y with(). Todos ellos son versiones inmutables de sus contrapartes mutables (sort(), reverse(), splice() y la asignación de índice arr[index] = value respectivamente). Adoptar estos métodos puede reducir la cantidad de código boilerplate que a menudo escribimos para crear copias de arrays antes de modificarlos (por ejemplo, usando el operador spread [...]).

toSorted(): Ordenación Inmutable

Similar a sort(), pero devuelve un nuevo array ordenado sin modificar el original. Es perfecto para mostrar datos ordenados sin alterar la fuente de datos. Puede recibir una función de comparación opcional. 


const numeros = [3, 1, 4, 1, 5, 9, 2];
const numerosOrdenados = numeros.toSorted((a, b) => a - b);

console.log(numeros);          // [3, 1, 4, 1, 5, 9, 2] (original sin cambios)
console.log(numerosOrdenados); // [1, 1, 2, 3, 4, 5, 9]

toReversed(): Inversión Inmutable

Esta es la versión inmutable de reverse(). Crea y devuelve un nuevo array con los elementos en orden inverso, dejando intacto el array original. 


const frutas = ['manzana', 'banana', 'cereza'];
const frutasInvertidas = frutas.toReversed();

console.log(frutas);           // ['manzana', 'banana', 'cereza'] (original sin cambios)
console.log(frutasInvertidas); // ['cereza', 'banana', 'manzana']

toSpliced(): Extracción/Inserción/Reemplazo Inmutable

toSpliced() es la versión inmutable de splice(). Es un método muy potente que permite añadir, eliminar o reemplazar elementos en cualquier posición del array, devolviendo un nuevo array con los cambios. 


const colores = ['rojo', 'verde', 'azul', 'amarillo'];

// Eliminar un elemento
const sinVerde = colores.toSpliced(1, 1);
console.log(colores);    // ['rojo', 'verde', 'azul', 'amarillo']
console.log(sinVerde);   // ['rojo', 'azul', 'amarillo']

// Insertar un elemento
const conNaranja = colores.toSpliced(2, 0, 'naranja');
console.log(conNaranja); // ['rojo', 'verde', 'naranja', 'azul', 'amarillo']

// Reemplazar un elemento
const moradoEnLugarDeAzul = colores.toSpliced(2, 1, 'morado');
console.log(moradoEnLugarDeAzul); // ['rojo', 'verde', 'morado', 'amarillo']

with(): Actualización de Elementos por Índice

El método with() es análogo a la asignación por índice (array[index] = value), pero de manera inmutable. Permite actualizar un elemento en una posición específica del array sin mutar el original, devolviendo un nuevo array con el elemento modificado. 


const tareas = ['Comprar pan', 'Escribir informe', 'Llamar a Juan'];

// Marcar la primera tarea como completada (modificándola)
const tareasActualizadas = tareas.with(0, 'Comprar pan (completado)');

console.log(tareas);            // ['Comprar pan', 'Escribir informe', 'Llamar a Juan']
console.log(tareasActualizadas); // ['Comprar pan (completado)', 'Escribir informe', 'Llamar a Juan']

// Intentar usar un índice fuera de rango lanza un error RangeError
try {
    tareas.with(5, 'Nueva tarea');
} catch (e) {
    console.error(e.name); // RangeError
}

Estos nuevos métodos son un gran paso hacia una manipulación de arrays más segura y expresiva en JavaScript, especialmente para aquellos que buscan abrazar patrones de programación funcional y mantener la inmutabilidad de los datos. ¡Anímate a integrarlos en tus proyectos!
